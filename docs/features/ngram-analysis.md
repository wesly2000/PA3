## Motivation
- Using n-gram for anomality detection in flow packet analysis faces the challenge that packet size varies in a wide range with small step (-1460->1460 vs. step of 1). It implies that the vocabulary for n-gram is overwhelmingly large which causes low Recall. We need to select a "proper" bin size to discretize the value space into several bins, each of which is a value in the vocabulary. 
- **Research Goal**: To balance the trade-off between Recall (bin size is too small, no anomality is detected) and Precision (bin size is too large, all windows are anomality).

## Design && Implmentation
Currently, the goals include mainly in 2 sides:

1. Ground truth labeling, which is provided by the rule-based stripper;
2. Plot the how the size of volcabulary affects Precision/Recall;
3. Implement mutual information (MI) based objective function to select optimal size of volcabulary.
